# 课程 review 旧新版复核

2026-09-20；旧版为 `/opt/course-review`，新版为独立原生插件。本轮目标是私有部署与验收，未修改生产课程服务或入口。

## 补齐的差异

| 范围 | 本轮处理 |
| --- | --- |
| 首页 | 恢复首页、近期 240 条公开课程评价的热门课程、最新课程评价、热门导师、最新导师评价；首页课程评价不混入导师评价。 |
| 顺序 | 按源 `createdAt` 排最新，不把导入后的自增 ID 当时间；热度按同课同教师聚合。中文标题同分顺序使用 PostgreSQL 中文 ICU 排序。 |
| 搜索 | 补齐课程序号、院系、类别、专业、导师研究方向，支持多词、中文简称、院系别名和三元组近似搜索；同名教师提供独立入口。 |
| 筛选与分页 | 学院、校区、学年、学期使用目录生成的选项；前后翻页、页码和总数，不再默默截断前 100 条。 |
| 课程分组 | 课程代码、标题、教师集合形成稳定组合，跨学期教学班汇总，评价仍绑定具体教学班。收藏跨教学班一致。 |
| 教学班 | 展示排课、学分、教师职称、地点、容量、考核等原始元数据，明确当前评价的教学班，保留任课教师入口。 |
| 导师 | 恢复职称、学位、特称、邮箱、简介、招生方向与学校来源链接。 |
| 评分 | 课程五项、导师三项，0.5–5 分、半星步长；显示一位小数；导师不再混入修读学期/再次选择等课程字段。 |
| 评价修改 | 预填本人评价，更新前确认；版本校验防止另一标签页修改被静默覆盖；最低 10 字、正文/建议长度与旧版对齐。 |
| 评价删除 | 本人删除后可以重新评价；清理其讨论与关联互动，评论删除保留其他回复并解除父关联。 |
| 隐藏状态 | 隐藏原因迁入并向本人/管理员展示；作者修改隐藏评价不会使其自动公开。 |
| 讨论 | 列表提供赞踩、讨论数量与入口；讨论页有匿名回复、父评论摘要、互斥赞踩和举报，回复至少 2 字。 |
| 个人页 | 分开查看自己的评价、评论和收藏，包含状态、编辑、删除、取消收藏和本人数据导出。 |
| 管理 | 可分页查看公开/隐藏课程评价、导师评价、评论及举报原文，直接处理目标内容并标记举报，保留操作记录。 |
| 通知 | 回复、点赞和管理处理链接到具体讨论，不泄露匿名发起人，不重放旧通知。 |
| 账号生命周期 | 停用插件时也清理删除/匿名化账号数据与原始归档；合并账号处理唯一性冲突。 |
| 历史链接 | 提供 `/courses/legacy/...` 映射旧课程 ID、课程组合键、教师键与导师来源编号；正式切换时再接旧域名重定向。 |
| 目录维护 | Excel 与导师抓取转换器生成独立 JSON，Rails 支持演练和 SHA 确认导入，更新不丢失评价关联。 |
| 界面 | 延续插件卡片风格，原生校园生活分组、深浅主题、窄屏表单、筛选下拉框、本地时区日期和浏览器前进后退。 |

## 真实数据快照

旧服务只读导出：8,782 个教学班、2,688 位导师、586 条课程评价、7 条导师评价、15 条评论、34 条赞踩、3 个收藏。131 个涉及账号的论坛 ID 都存在，旧登录来源为同一论坛。原始计数与互动明细核对一致。

私有数据库导入前先演练回滚，然后按 SHA 确认写入。逐字段核对包含原始归档、用户归属、时间戳、评论父子关系、评分、收藏规范键和导师全部元数据。226 条匿名评价与 1 条隐藏评价保持原状态。导入不产生 Command/Event 或历史铃铛。

真实快照仅在已有私有测试环境开放，并保持 `courses_read_only=true`。该隔离快照有用户映射但没有生产用户组成员关系，所以此入口限私有测试管理员。演示库使用合成课程、导师和评论，可验证真实写入；生产组规则在正式切换时按 `verified_uestcer,zjuer` 和原管理组配置。

## 验证与边界

后端回归覆盖首页热度与时间排序、分组筛选、导师信息、半星与长度限制、更新版本确认、删除后重新评价、隐藏不被覆盖、匿名回复、互斥赞踩、通知路径、管理越权、收藏、分页、只读限制、账号删除/合并、个人导出、旧链接、请求幂等和目录更新。

本轮验收已完成：后端 15 项测试、93 项断言全部通过；真实快照 132,862 项字段核对通过。真实数据入口返回只读错误，未产生业务命令或通知事件。浏览器验证发布及确认修改、匿名楼中楼、赞踩、通知链接、隐藏与恢复、导师评价、个人导出、历史前进后退、筛选分页和共同侧栏，JavaScript 错误为 0。浅色与深色主题、320/390/768/1440 像素布局均通过；截图保存在下述受限目录。

真实目录抽样中，首页、目录搜索和教师列表响应约 0.15–0.51 秒；这是单用户抽样，不代表并发压力测试。Excel 与导师 HTML 离线转换样例通过；插件资源已完整预编译，私有入口健康检查正常。

浏览器验收及私有数据对账的完整日志、截图和密码文件放在受限的 `/opt/course-private-preview` 与原私有入口凭据目录，不进入 Git。真实数据截图同样不得作为公共仓库示例。

保留的边界：举报使用插件管理页，未接全站 Reviewable；个人导出有独立入口，未嵌入 Discourse 全站导出归档；目录工具为命令行，没有另造论坛后台 Excel 上传页。导师抓取器沿用旧站解析规则，离线 HTML 样例验证通过，本轮不批量请求学校网站。课程与导师资料只迁移文本，不搬运外部头像。

正式上线前仍需建立插件仓库、固定提交，在停止旧写入后重新导出最新快照，并按相同流程对账、配置生产组、启用新入口和旧域名重定向。测试快照不会覆盖生产数据。

## 正式发布前末轮核对

末轮追加：评分由默认 4 分改为逐项必选并展示难度等方向提示；修读学期使用选项；评论 500 字、举报理由 240 字与旧站一致；补齐全文近似匹配、中文简称字符组合和精确搜索权重，导师按相关度排序；收藏展示完整课程组合统计；排课按行显示；导师邮箱提供发邮件链接；旧首页 tab、搜索及学年等参数有专用映射。

末轮后端 16 项测试、108 项断言全部通过。更新后的浏览器流程再次通过，评分未选会阻止提交，已有评分正确预填，课程与导师评价均可保存。正式发布使用独立课程插件版本库，真实导出、数据库备份、凭据和截图均不进入该仓库。
