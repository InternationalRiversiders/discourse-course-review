# 选课指南卡片与评价表单

课程卡片：课程名在左上，综合评分和评价数在右上；教师、课程代码、校区和教学班信息位于下方。原生标题链接覆盖卡片区域，支持键盘和新标签页；移除重复的课程详情入口。

评价卡片：先课程信息，再小头像/论坛名片、再次选择意愿标签及右侧时间。学期在作者行下方；课程/导师页内不重复对象名称。保留全部评分、建议、匿名状态和管理权限，互动集中于末行，仅展开当前选中的讨论/举报/管理表单。卡片链接不会覆盖名片、图片或操作区。

筛选：搜索框、图标和按钮统一高度；更多筛选位于搜索说明右侧，折叠保留筛选字段与当前值。

表单：评分改为支持半星的原生单选控件（0.5–5 分），支持键盘及必填验证。修读学年和学期分别选择，仍提交原有 term_taken 字符串；未填写、已有半分评分和不规则历史学期均保留。只填学年或学期时提示补全。

不改数据库结构、权限或匿名策略。API 仅新增供布局使用的评价展示字段。
